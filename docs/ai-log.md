# AI 활용 기록

수업 안내에 따라 목적, 핵심 요청, 채택·수정한 내용, 검증 방법을 남깁니다.

## 2026-10-28 · 설계와 첫 뼈대
- **도구**: Claude (Claude Code)
- **목적**: 팀이 정한 아이디어를 바탕으로 기술 구성 비교, 설계 문서, 첫 작동 버전 뼈대 만들기
- **핵심 요청**: "가족 대상 질문 카드 + 관찰로 모으는 유물 친구를 Flask로, 배포는 빠른 곳으로 설계하고 만들어 줘"
- **채택한 것**
  - 기술 구성: Vercel(Flask) + Neon(Postgres). Render 무료의 1분 대기와 파일 소실, Supabase 무료의 7일 정지 문제를 근거로 비교해 골랐다.
  - 화면 6개, API 3개, 콘텐츠 파일 검사, 조사 자동 처리, 도감 이미지 저장
- **사람이 정한 것**: 아이디어와 대상(가족), 박물관 후보(활박물관), 서버 담당과 역할 나눔
- **검증 방법**
  - pytest 45개, node 테스트 14개 통과
  - 휴대폰 크기 브라우저에서 시작부터 도감까지 직접 진행, 화면 버그 1건 발견 후 수정(숨김 처리)
  - 임시 Postgres 서버로 이벤트 저장·통계 확인
- **아직 사람이 확인할 것**: 예시 카드의 관찰 질문과 그림은 실제 유물이 아니다. 현장 방문 뒤 바꾼다.

# 콘텐츠 고치는 법

코드를 몰라도 됩니다. 질문, 이야기, 사진은 모두 `content/tour.yaml` 한 파일과 `public/img` 폴더에 있습니다.
GitHub 웹사이트에서 고치고 PR(변경 요청)을 올리면, 자동 검사가 틀린 곳을 알려 줍니다. 검사가 초록색이 되면 서버 담당이 합쳐서 배포합니다.

## 고치는 순서
1. GitHub 저장소에서 `content/tour.yaml` 을 엽니다.
2. 오른쪽 위 연필 버튼을 누릅니다.
3. 글자를 고칩니다. 들여쓰기(맨 앞 띄어쓰기)는 건드리지 않습니다.
4. **Commit changes** 를 누르고 **Create a new branch** 를 고른 뒤 **Propose changes** 를 누릅니다.
5. **Create pull request** 를 누릅니다.
6. 몇 분 뒤 PR 아래에 검사 결과가 뜹니다. 빨간 X가 뜨면 **Details** 를 눌러 한국어 오류 문장을 읽고 같은 브랜치에서 다시 고칩니다.

## 카드 한 장의 모양
```yaml
  - code: "101"                 # 유물 옆에 붙일 번호. 따옴표 안에 숫자 세 자리
    name: 신기전기화차           # 친구 이름 (20자 이하)
    find: 화살을 아주 많이 꽂을 수 있는 큰 수레를 찾아볼까?   # 부모가 읽어 줄 찾기 질문
    hint: 입구에서 가장 먼저 보이는 유물이에요.               # 막힐 때 보는 힌트
    observe:
      question: 화살 구멍은 몇 줄이야?    # 아이가 실물을 봐야 답할 수 있는 질문
      choices: [3줄, 5줄, 7줄]           # 보기 2~4개
      answer: 5줄                         # 보기 중 하나와 글자까지 똑같이
    story: 화약을 단 화살을 100발까지 한꺼번에 쏠 수 있었어요.   # 부모가 읽어 줄 짧은 이야기 (사실만)
    imagine:
      question: 너라면 화살 대신 무엇을 날려 보낼래?
      line: "나는 {답}{을/를} 날려 보내고 싶은 화차야!"   # {답} 자리에 아이 대답이 들어감
      skip_line: 나는 화살 100발을 한꺼번에 쏘는 화차야!   # 아이가 대답을 건너뛰었을 때
    image: img/101.webp          # public/img 안의 파일
    image_alt: 화살 구멍이 여러 줄 뚫린 나무 수레   # 그림을 못 보는 사람을 위한 설명
    face: {x: 50, y: 45, size: 40}   # 눈·입 위치. 그림 왼쪽에서 x%, 위에서 y%, 얼굴 너비 size%
    source: 이야기의 출처
    image_credit: 사진 출처와 허락 범위
    checked_by: ""               # 학예사 등이 확인하면 역할을 적음. 예: 부천활박물관 학예사
    note: 팀 메모 (화면에 안 나옴)
```

## 꼭 지킬 것
- **관찰 질문은 실물을 봐야 풀리게** 만듭니다. 설명판만 읽어도 풀리면 다시 씁니다.
- **이야기에는 확인된 사실만** 씁니다. 출처를 `source` 에 적습니다.
- 대사의 조사는 아이 대답에 따라 자동으로 바뀝니다. `{을/를}` `{이/가}` `{은/는}` `{과/와}` `{아/야}` `{으로/로}` 만 씁니다. "젤리"면 "젤리를", "사탕"이면 "사탕을"이 됩니다.
- 대사에 `{` 가 들어가면 줄 전체를 큰따옴표로 감쌉니다.
- 사진은 촬영 허락 범위를 확인한 것만 씁니다. 관람객 얼굴이 나온 사진은 쓰지 않습니다.
- 사진 파일은 300KB 이하로 줄여 `public/img` 에 올리고, 이름은 번호로 짓습니다. 예: `101.webp`
- 투어 맨 위 `status` 를 `확정` 으로 바꾸면, 모든 카드에 `source`, `image_credit`, `checked_by` 가 있어야 검사를 통과합니다.

## 눈·입 위치 맞추기
`face` 의 x, y 는 그림 왼쪽 위에서부터의 위치(%)입니다. 50, 50 이면 정가운데입니다. size 는 그림 너비 대비 얼굴 너비(%)입니다.
배포 미리보기에서 친구 화면을 보고 숫자를 5씩 바꿔 가며 맞춥니다.
